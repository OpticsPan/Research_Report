# 行业调研报告

这里维护行业调研报告的正文、关键数据来源和修订记录。阅读已发布的研究，请看[报告目录](reports/README.md)。报告发布、重要勘误和协作流程调整见[仓库变更记录](CHANGELOG.md)。

[专利资料库](materials/patents/README.md)收录从原始 PDF 转写的 Markdown 全文，供报告引用和 AI 检索。

## 单分支管理

`main` 是仓库唯一分支。新增报告、资料归档、勘误以及仓库管理变更都直接提交到 `main`。保留每次提交和已有合并历史，不创建工作分支或新 PR。

提交前先读取最新的 `main`，按[提交前检查清单](templates/pre-commit-checklist.md)复核本次改动。写入时若 `main` 已有新提交，先核对差异、整合他人的更新，再重新检查并提交。修正已发布内容时追加更正提交，保留原记录。

## 开始一份报告

1. **选题**　在 [Issues](https://github.com/OpticsPan/Research_Report/issues/new/choose) 选择「研究选题」，写明报告面向谁、要回答什么问题、覆盖哪些市场和年份。认领选题后，在 Issue 上指定负责人。查阅[用户偏好](PREFERENCES.md)，把本篇的特殊要求写入选题 Issue。
2. **撰写**　在最新的 `main` 上准备改动。在 `reports/<行业>/<YYYY-MM>-<主题>/` 下复制[报告模板](templates/report.md)为 `README.md`，复制[来源表](templates/sources.md)为 `sources.md`。例如，`reports/储能/2026-11-工商业储能需求/`。月份取首次发布月份，修订沿用原目录。
3. **审阅**　在[报告目录](reports/README.md)增加条目，按[提交前检查清单](templates/pre-commit-checklist.md)核对结论、统计口径和估算过程。涉及主要结论的疑问应在发布前处理，可在选题 Issue 中记录讨论。
4. **发布与修订**　将核对后的变更直接提交到 `main` 即为发布，提交说明关联选题 Issue（如有）。后续数据更新或勘误追加提交，同步更新正文的修订记录和目录中的数据截止日。引用特定版本时使用该版的 GitHub 提交链接。

## 引用与数据口径

- 在关键数字、图表和可核验结论旁标注来源编号，例如 `[S01]`。在同目录的 `sources.md` 记录原始出处、发布日期和具体页码、表号或章节。
- 比较市场规模前，先说明地区、统计期、单位和指标定义。例如，出货量和装机量分别列示。引用预测值时注明预测机构和预测时间。
- 自行估算的数据标明「估算」，列出公式、输入值及其来源，并说明哪个假设最影响结果。来源冲突时，记录采用某个数字的理由。
- 本仓库公开可读。引用付费或受限材料时记录可公开的书目信息与定位，仅上传可公开分发的图表、数据和附件。

## PDF 来源转写

本仓库使用 PDF 作为研究来源时，先取得原件并逐页转为 Markdown，再据此摘录或引用。新来源和换版的 PDF 均按本流程处理。

1. **启动转换。** 在已启用 `convert-pdf-to-markdown`（PDF 转 Markdown）的网页版 ChatGPT「工作」对话中，附上一份或多份原始 PDF，发送“用 PDF 转 Markdown 技能逐份转写附件，保留原文、表格和每一页的页码，列出无法辨认的位置”。如果换了工作区，先确认技能可用。转换由这次对话触发。
2. **处理文字页和扫描页。** 技能用 pdfplumber 提取文字和有边框的表格。扫描页用对应语言的 Tesseract OCR 生成初稿。缺少中文语言包时，在对话中逐页看原图转写。图文混排页同时核对文字层和图片中的文字、数字、图注。
3. **验收。** 每份 PDF 生成一份 UTF-8 Markdown。从封面起按原件物理页序核对到末页，空白页和纯图页也保留页码。抽查文字页，逐页对照扫描或混排页，重点查双栏顺序、表格行列、数字、正负号、单位和公式。无法辨认处标为 `[待核对：PDF 第 N 页，位置]`。分开记录缺页与文字疑点，批量任务按文件列出成功、待核对或失败的结果。原件加密或损坏时记录原因并索取可读版本，其余文件继续处理。
4. **归档与引用。** 可公开分发的转写稿放入相应资料目录，沿用该目录的命名和页码格式。同一版本已有逐页稿时先复核并复用。报告的 `sources.md` 用同一来源编号登记原始出处、具体页码和转写稿相对链接。付费或受限材料只登记可公开的书目信息和定位，原件及其全文转写均不提交到公开仓库。
