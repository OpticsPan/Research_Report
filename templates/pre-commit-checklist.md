# 提交前检查清单

提交到 `main` 前，按本次变更的实际范围核对。

- [ ] 已读取最新的 `main`，核对本次修改的文件和差异。
- [ ] 提交说明概括新增内容或修订原因，并关联选题或勘误 Issue（如有）。若结论改变，已说明依据。

## 变更登记

- [ ] 已按 `CHANGELOG.md` 的收录范围补充本次记录，并链接相关报告、Issue 或提交。如仅改正错字或排版，可勾选并注明「仅文字整理」。

## 报告审阅

- [ ] 已对照选题 Issue 的本篇要求和仓库的 [长期偏好](https://github.com/OpticsPan/Research_Report/blob/main/PREFERENCES.md) 核查交付内容。

- [ ] 核心结论回答了选题问题，关键数字、图表及判断可按来源编号定位到原文。
- [ ] 如引用专利，已单独核对资料库中的逐页稿及其覆盖范围，并从报告来源表链接原件和逐页稿。待补项已在索引和来源表标出。
- [ ] 数据已标明期间、单位和统计口径；跨来源比较说明了差异。
- [ ] 如有估算，已复核公式、输入和假设，并区分实测值与预测值。
- [ ] 目录链接、数据截止日和修订记录已更新；附件适合公开分发。
- [ ] 如使用 PDF，已按[转写规范](https://github.com/OpticsPan/Research_Report/blob/main/README.md#pdf-来源转写)核对原件页数、关键数字及来源链接，并注明缺页、无法辨认处或受限材料的处理情况。

仅修改仓库管理文件时，核对受影响的说明、模板和链接即可。
