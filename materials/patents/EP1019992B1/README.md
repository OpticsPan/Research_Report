# EP1019992B1 · 准分子激光脉冲能量控制

Cymer，欧洲授权公报，2006-06-14。优先权日为 1997-10-10。原始说明书为英文。以下是按 PDF 页码整理的中文技术摘录。页码从封面起计，共 23 页。[公报 PDF](https://patentimages.storage.googleapis.com/56/01/0c/4efa593a4f8050/EP1019992B1.pdf) · [可检索文本](https://patents.google.com/patent/EP1019992B1/en)

| PDF 页码与定位 | 技术内容 | 与光刻机的关系 |
| --- | --- | --- |
| 第 3 页，[0009]–[0012] | 背景例为 1 kHz，每串约 110 次脉冲，串间可停约 0.2 秒至数秒。停顿后重启，串首能量会偏离稳态。 | 移场和换片会打断激光工作。即使平均功率合格，单场累计曝光仍可能偏移。 |
| 第 3–4 页，图 1、2 的说明 | 图 1 画出既有商用 KrF 光源的主要元件，图 2 给出固态脉冲电源。 | 识别传感、充电和放电的接口；图内元件数不能换算为机柜 PCB 数。 |
| 第 9 页，[0044]–[0049] | 通过小幅改变充电电压估计能量响应；增大校正幅度会在收敛速度与稳定性间形成取舍。 | 电源输出、能量探测与控制算法须联合验证。 |
| 第 10 页起，权利要求 1 | 控制器同时使用先前脉冲的能量偏差、本串累计剂量偏差、电压响应斜率与参考电压，设定后续脉冲。 | 对单脉冲与整串分别验收；还需区分激光器出口能量和晶圆面剂量。 |

上述参数用于解释该专利的工作模式。ASML /350C 的光源型号及曝光场反馈由原厂规格和装机资料另行确认。[权利要求原页](https://patentimages.storage.googleapis.com/56/01/0c/4efa593a4f8050/EP1019992B1.pdf#page=10)
