# US6084673A · 扫描曝光的双台干涉测量

美国授权公报，封面受让人为 ASM Lithography B.V.，公开日 2000-07-04，最早优先权日 1996-03-04。以下为英文 PDF 的中文技术摘录，页码从封面起计，共 27 页。[公报 PDF](https://patentimages.storage.googleapis.com/8e/53/50/5ca8d0ec153924/US6084673.pdf) · [可检索文本](https://patents.google.com/patent/US6084673A/en)

| 末页权利要求 | 技术结构 | 能够解释的难点 |
| --- | --- | --- |
| 1 | 掩模架和基片架的反射侧面作为测量镜。扫描中，两套干涉系统跟踪相对位置。 | 运动台读数与实际图形位置之间的机械链越长，可引入误差的环节越多。 |
| 2、3 | 一种方案用五轴基片干涉仪和至少三轴掩模干涉仪。另一种用三轴基片干涉仪加非接触传感器补测。 | 同一控制目标允许不同测量架构，不能从受控自由度倒推传感器或驱动板数量。 |
| 8–10 | 将位置读数转换为平移、转角或倾斜控制量；另列固定反射器参考轴，以及在测量光路供应折射率稳定空气的方案。 | 气流会改变干涉光程，同时影响位置读数。 |

这些是权利要求覆盖的设计选项。具体 PAS 机型使用哪种组合，需要配置资料或测量链图。[PDF 第 27 页](https://patentimages.storage.googleapis.com/8e/53/50/5ca8d0ec153924/US6084673.pdf#page=27)
