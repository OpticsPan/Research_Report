# 专利资料库

这里保存专利原始 PDF 的 Markdown 转写。每个公开号使用一个目录，保留国家或地区代码和文献种类代码。多篇报告引用同一公开文本时，共用同一份转写稿。

## 独立交付与引用

每件用于报告的专利单独归档。交付文件为 `materials/patents/<公开号>/fulltext.md`，同目录的 `README.md` 可存研究摘录和引用入口。报告撰写与原件转写分别记录进度。

逐页稿须从封面起标出连续页码，覆盖到 PDF 末页，包括权利要求和纯图页。验收时核对公开号及文献种类、原件链接、总页数、图表和公式是否对应原页。将页数覆盖与文字校对分别记录，OCR 疑点定位到原页。原件尚未取得时在索引登记「待原件」，只完成部分页时登记实际覆盖页码。

## 收录方法

先将目标版本 PDF 下载到本地，再用本地 MineU 按物理页序输出 Markdown。若公开阅读器逐页提供 PDF，可以按原序合本，记录来源、附加的文摘页、总页数和合本校验值，不能将合本指纹当作发行方文件的指纹。

1. 在本目录下新建以完整公开号命名的目录，把[转写模板](TEMPLATE.md)复制到其中，命名为 `fulltext.md`。填写原文标题、申请人、公开日、原文语种和 PDF 来源。
2. 按 PDF 的原文顺序转写全文。在每页起始处用二级标题标记 `## PDF 第 1 页` 等页码，从 PDF 首页起按 1 计数。保留原段落号、权利要求编号及其从属引用、实施例号、图号和表号。如需翻译或解读，另设小节并注明。
3. 表格保留行列、单位和脚注。逐项核对 OCR 容易混淆的数字、负号、上下标和公式符号。识别不清的位置写作 `[待核对：PDF 第 N 页，位置]`。部分转写须注明覆盖页码。
4. 提取的附图放在该公开号目录的 `figures/` 中，在正文对应位置使用相对链接嵌入，并写明原图号、页码和简短说明。
5. 在下方索引登记转写稿。报告引用时，在报告的 `sources.md` 中同时链接转写稿及原始 PDF，并注明具体页码、权利要求、实施例或图表编号。
